# 身份码 · 一键直达

取快递时不用再"先扫码才能打开身份码"了 —— 手机桌面点一下，直接到身份码。

## 怎么用

1. 手机浏览器打开本站，**添加到主屏幕**（名字建议填「身份码」）。
2. 打开页面 → 在「① 设置身份码链接」里粘贴身份码的链接 → **保存**（只需一次）。
3. 以后取件：桌面点「身份码」→ 点大红按钮 → 出码。

## 链接怎么拿

下次取件时用手机相机或微信「扫一扫」扫驿站的二维码，**先别点确认进入**，把显示的链接复制下来填进去。
懒得复制就直接给二维码截个图，用页面里的「扫二维码截图」识别。

## 说明

- 纯静态页面，**你的链接只保存在你自己手机的浏览器里**（localStorage），不会上传到服务器，本仓库里也没有任何个人信息。
- 首次打开后会被浏览器缓存，取件时**没网也能打开**。
- 支持三种链接：`https://mobile.yangkeduo.com/...` 网页链接、`pinduoduo://com.xunmeng.pinduoduo/...` App 直达、以及任意自定义 scheme（在安卓上会自动尝试 `intent://` 方式唤起，成功率最高）。
- 如果驿站二维码里的链接每次都变（带一次性参数），说明是动态码，绕不过去；此时可把桌面图标当作「直接进拼多多身份码」的入口使用。

## 想再省一步

装 **HTTP Shortcuts**（安卓，免费开源），新建一个「打开网址」快捷方式，填入你的链接，桌面图标点一下即达终点。

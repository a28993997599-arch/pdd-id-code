① 设置身份码链接只需设置一次

也可以直接扫二维码截图：手机截图后点上面的「扫二维码截图」，或在电脑上把二维码图片拖进来。

② 怎么拿到这个链接？（1 分钟）
  1. 下次取件时，用手机相机或微信扫一扫对着驿站那个二维码扫一下。
  2. 先别点确认进入，看屏幕上显示的链接内容。
  3. 把它复制下来，粘贴到上面的框里 → 保存。搞定。
  4. 懒得复制？直接截图那个二维码，然后用上面的「扫二维码截图」，我帮你认。
③ 怎么放到手机桌面（点一次，以后都在桌面）
  1. 用手机 Chrome / Edge / 夸克等浏览器打开本页。
  2. 先把链接保存好（这一步只做一次）。
  3. 浏览器菜单 → 「添加到主屏幕 / 添加到桌面」，名字填「身份码」。
  4. 以后取快递：桌面点「身份码」→ 点大红按钮 → 出码。

想再省一步（连这一屏都不要）：装 HTTP Shortcuts（安卓免费、开源），新建一个「打开网址」的快捷方式，把链接填进去 → 桌面图标点一下就是终点。这是安卓上最干脆的做法。

④ 点了没反应 / 打不开怎么办
  1. 链接是 https://…：正常会在浏览器里打开；如果页面提示「打开拼多多」，选允许。
  2. 链接是 pinduoduo://…：安卓 Chrome 有时会拦这种跳转。本页会自动尝试 intent:// 方式唤起（安卓成功率最高）；还不行就用 HTTP Shortcuts / Tasker，或者点「复制链接」粘到拼多多里打开。
  3. 如果驿站二维码里的链接每次都变（带一次性参数），说明它是动态码，绕不过去。那就把桌面图标当成「直接进拼多多身份码」的入口用，一样能省掉大半步骤。
  4. 拼多多升级后入口若变化，链接失效的话，回来重新抓一次二维码填进去即可。
